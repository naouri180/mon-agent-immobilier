# 2. Installer « Mon Agent Immobilier » sur l'iPhone

1. Ouvrez **Safari** (pas Chrome : l'installation passe par Safari sur iPhone).
2. Allez à `https://VOTRE-PSEUDO.github.io/mon-agent-immobilier/`.
3. Touchez le bouton **Partager** (carré avec une flèche vers le haut).
4. Faites défiler et touchez **Sur l'écran d'accueil**.
5. Le nom proposé est « Mon Agent Immo » ; modifiez-le si vous voulez, puis **Ajouter**.

L'icône rouge à la maison apparaît sur l'écran d'accueil. L'application s'ouvre en plein écran, sans barre Safari, et reste consultable hors connexion avec les dernières données chargées.

## Au quotidien

- **Accueil** : meilleures opportunités, nouvelles annonces depuis votre dernière visite, baisses de prix, et l'heure du dernier passage de l'agent.
- **Annonces** : toutes les annonces, avec tri et filtres. Les annonces retirées ou vendues sont dans l'onglet « Retirées ».
- Touchez une annonce pour la fiche complète : détail de la note, historique du prix, points faibles, vos notes, lien vers l'annonce d'origine. L'ouvrir la marque comme consultée.
- **Favoris** : touchez le cœur sur une carte.
- **Réglages** : vos critères, l'état de l'agent par source, l'abonnement aux alertes, les liens de recherche vers les grands portails, la sauvegarde.
- Le bouton rond en haut à droite recharge les données ; elles se rechargent aussi à chaque ouverture.

## Bon à savoir

- Favoris, biens consultés, notes et critères sont enregistrés **sur ce téléphone**. Pour les transférer : Réglages → Sauvegarde → Exporter, puis Importer sur l'autre appareil.
- Si vous supprimez l'icône ou effacez les données de Safari, ces informations locales sont perdues : exportez-les d'abord.
- Après une mise à jour de l'application, fermez-la puis rouvrez-la une ou deux fois pour charger la nouvelle version.
